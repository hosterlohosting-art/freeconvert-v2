Image Formats Glossary & Definitions

PNG (Portable Network Graphics): A lossless compressed raster format that records pixel data exactly as created. It supports full alpha transparency, making it the perfect choice for logos, typography, and clean graphic assets.

JPG / JPEG (Joint Photographic Experts Group): A lossy compressed raster format optimized for photograph color depth. It compresses file weights aggressively by discarding visually subtle variations, speeding up webpage loading.

WebP (Web Picture Format): Google's next-gen lossy and lossless image standard. It compresses image weights by 30% more than traditional JPEGs, directly boosting Google Core Web Vitals rankings.

SVG (Scalable Vector Graphics): An XML-based vector graphics standard. Rather than storing a grid of pixels, it stores geometric paths, enabling graphics to scale to infinite sizes with zero blurring.

Rotate Image format notes

Before rotating, check whether your goal is a straight photo, a mirrored flip, or a new format. Rotating re-saves the image: PNG stays lossless, while JPG and WebP lose a tiny amount of quality each time. PNG and WebP keep transparency; JPG does not, so transparent areas turn black. When quality matters, keep a backup of the original file and compare the result before deleting anything.

Frequently Asked Questions (FAQ)

Does rotating change my photo's quality?

Rotating re-saves the image. PNG stays lossless, so nothing is lost. JPG and WebP lose a tiny amount of quality each time they are re-saved — rotate once and you will not notice it.

Are my files uploaded to your servers?

No. Rotation runs client-side using JavaScript. Your files are rotated in browser memory and are never uploaded, ensuring complete privacy.

Which image formats can I rotate?

PNG, JPG, JPEG, and WebP. Other formats are not supported yet.

What happens to transparency when I rotate?

PNG and WebP keep transparency. JPG does not support transparency, so transparent areas turn black when saved as JPG.

What is the file size limit?

One file at a time, up to 50 MB, so the rotation stays fast in your browser's memory.
