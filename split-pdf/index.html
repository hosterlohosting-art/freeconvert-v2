Document Formats Glossary & Definitions

PDF (Portable Document Format): Adobe's fixed-layout document standard. It embeds fonts, vector graphics, and raster images identically, ensuring document formatting never shifts regardless of operating system or screen size.

DOCX (Word Document): Microsoft's fluid XML-based editing container. Perfect for drafting and copywriting, but susceptible to formatting shifts if opened on systems lacking the author's local fonts.

Splitting PDFs: Dividing one PDF into smaller PDFs — one file per page, one file per page range, or two files cut at a chosen page. A good split copies each page exactly, so text, links, and images stay as they were in the original file.

Frequently Asked Questions (FAQ)

Is this Split PDF tool free to use?

How many pages can I split at once?

You can split one PDF of up to 50MB with up to 500 pages. In every-page mode a 500-page file gives 500 small PDFs — download them all at once as a ZIP file.

Does this tool upload my files to any server?

No. All splitting for Split PDF happens locally on your computer inside the browser memory. Your files are completely safe and never touch our servers.

Will the text in my split PDFs still be selectable?

Yes. Pages are copied exactly as they are, so text, links, and images stay just as they were in the original file. Nothing is re-rendered.

Can I split a password-protected PDF?

No. Password-protected (encrypted) PDFs cannot be split here. Remove the password first, then add the file again.

After you split every page, click “Download All as ZIP” to get one ZIP file with a PDF for each page. You can also download pages one by one from the list.

Does splitting make my PDF smaller?

No. Splitting only divides the pages — the split files together are about the same size as the original PDF. If a file is still too large, use Compress PDF to shrink it.
