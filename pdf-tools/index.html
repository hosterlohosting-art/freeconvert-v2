Document Formats Glossary & Definitions

PDF (Portable Document Format): Adobe's fixed-layout document standard. It embeds fonts, vector graphics, and raster images identically, ensuring document formatting never shifts regardless of operating system or screen size.

File Compression: The algorithmic optimization of document sizes, which identifies duplicate data arrays and compacts graphic payloads to fit strict email file constraints.

Frequently Asked Questions

Have questions about our PDF tools? Read our FAQ below:

Do my PDF files leave my computer?

No. The PDF tools on this page run entirely in your browser. Your file is never uploaded to a server.

Does compressing a PDF degrade the text quality?

Our Compress PDF tool works best on scanned and image-heavy PDFs: it shrinks the images inside. Pages are re-rendered as images, so text in the compressed file is no longer selectable, and a text-only PDF may barely shrink. Merge PDF and Split PDF copy pages exactly, so text stays selectable there.

Are these PDF tools really free?

Yes. All five tools on this page are free, with no sign-up.

Can I use these PDF tools on my phone?

Yes. The tools work in modern mobile browsers. For very large PDFs, a desktop browser is usually faster.
