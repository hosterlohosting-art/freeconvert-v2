About our Document Tools Directory

This page is a directory of free document and text tools on freeconvert.cloud. The general document converter is being rebuilt and is not available yet, so this page has no upload box. Pick any tool in the list above and it opens on its own page.

Why Choose freeconvert.cloud for Document Tools?

Every tool listed here is free, with no sign-up. The text, code, and data tools run in your browser, and the PDF tools linked above run entirely in your browser too - your files are never uploaded. We keep the pages free with simple advertising, and we do not use deceptive download buttons.

Primary Use Cases

  • Format and check JSON data before you paste it into an app or API.
  • Encode or decode Base64 and URL text for development work.
  • Count words and characters in a document or post.
  • Minify CSS and JavaScript files to make web pages load faster.
  • Convert PDF pages to JPG images, or turn JPG images into a PDF, with the working PDF tools linked above.

Supported Formats and Guides

The tools in this directory work with text, JSON, CSV, YAML, Base64, and code. For PDF files, use the working PDF tools linked at the top of this page: PDF to JPG, JPG to PDF, Compress PDF, Merge PDF, and Split PDF.
