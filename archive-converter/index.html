About our Archive Converter Hub

Free archive tools that run entirely in your browser. Pack several files into one ZIP archive, or open a ZIP archive and download the files inside — no uploads, no sign-up, and your files never leave your computer. ZIP is the only archive format this hub supports.

What is an archive file?

An archive is a single file that holds one or more files inside it, usually compressed so the total is smaller. ZIP is the most widely supported archive format: Windows, macOS, and Linux can all open ZIP files without extra software. Archives are used to send several files as one attachment, to back up a folder, or to bundle downloads into a single file.

The two archive tools

  • Create ZIP: add files of any type and pack them into one standard ZIP archive, up to 200 MB in total. Choose Standard, Maximum, or no compression.
  • Extract ZIP: open a ZIP file up to 200 MB, see the files inside, and download the ones you need — one at a time, without unpacking everything.

How to create a ZIP archive

  1. Open Create ZIP and drop your files into the box, or click Choose Files.
  2. Name the ZIP and pick a compression level — Standard is the best balance of size and speed.
  3. Click Create ZIP, then download the archive. It opens in Windows, macOS, Linux, and any unzip tool.

How to extract a ZIP archive

  1. Open Extract ZIP and drop your ZIP file into the box, or click Choose ZIP File.
  2. Click Open ZIP to read the archive and see the files inside.
  3. Click Download next to any file to save it. Each file is read from the archive only when you click its button.

What this hub does not do

This hub works with ZIP files only. RAR, 7Z, TAR, and GZ archives cannot be opened here. Password-protected ZIP files cannot be opened either — the browser tool cannot decrypt them, so use your operating system's unzip tool instead. Archives are not encrypted and have no password option. The total size limit is 200 MB, because everything happens in your browser's memory.

Frequently Asked Questions (FAQ)

Do my files leave my computer?

No. Both archive tools run entirely in your browser with JSZip. Your files are never uploaded to a server.

Can I open RAR or 7Z files here?

No. This hub works with ZIP files only. RAR, 7Z, TAR, and GZ archives use different formats that this browser tool does not support.

Can I open a password-protected ZIP?

No. Password-protected ZIP files cannot be opened here — the browser tool cannot decrypt them. Use your operating system's unzip tool instead.

Are these archive tools really free?

Yes. Both tools on this page are free, with no sign-up. The only limit is 200 MB of files per archive.
