What is a ZIP file?

A ZIP file is a single archive that holds one or more files, usually compressed so the total is smaller. ZIP is the most widely supported archive format: Windows, macOS, and Linux can all open ZIP files without extra software. Inside, each file is stored with its name and a checksum, so a damaged archive can be detected instead of silently giving you wrong files. Extracting a ZIP means reading that list and saving the files back out.

Frequently Asked Questions (FAQ)

Is my ZIP file uploaded to a server?

No. The whole extraction runs in your browser with JSZip. Your archive never leaves your device.

Can I open a password-protected ZIP?

No. Password-protected ZIP files cannot be opened here — the browser tool cannot decrypt them. Use your operating system's unzip tool, or ask the sender for an unprotected copy.

Can I open RAR or 7Z files?

No. This tool opens ZIP files only. RAR, 7Z, TAR, and GZ archives use different formats that this browser tool does not support.

What if my ZIP file is damaged?

The tool tells you plainly instead of failing silently. A corrupt or incomplete archive may not open at all; if it opens, damaged entries may fail to download. Try re-downloading the ZIP from its source.

How big can my ZIP be?

The ZIP file must be 200 MB or less, and the files inside must total 200 MB or less when unpacked. Everything happens in your browser memory, so bigger archives can crash the tab.
